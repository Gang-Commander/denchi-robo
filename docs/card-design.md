# カード設計書（アドベンチャー＝勝ち抜きローグライト用）

モード名（10/21 決定）：クイック対戦（旧スタンダード）／アドベンチャー（旧勝ち抜きモード）／カスタム対戦（予定：集めたカードで自由構築）。コード上の名前は standard / run（rogue）のまま。

最終更新：2026-10-20（全カード・ローグライトの1ランを実装済み。特殊イベント・実績は未実装）

## 新しいルール

### ロボへのダメージ
- ロボの攻撃力は体力も兼ねる。
- ロボが受けたダメージは、その手番の間は残る。**手番の終わりに全て取り除かれる。**
- ダメージを受けたロボの攻撃力は、受けたダメージの分だけ下がる（例：攻撃力5に3ダメージ → 攻撃力2として扱い、表示も2）。
- **ダメージを受けていて、かつダメージの合計が攻撃力以上なら破壊**される。ダメージのない攻撃力0のロボは破壊されない。
- 電池が外れて攻撃力が下がり、ダメージ以下になった場合も破壊される。
- 戦闘のルールは変えない（攻撃力を比べ、低い方が破壊、差分が持ち主へのダメージ）。

### キーワード
- **付属電池**：電池を1本入れた状態で場に出る。
- **満充電**：電池が上限まで入っている間だけ働く効果。
- **バトンタッチ**：破壊された時、入っていた電池を自分の場のロボに移す（攻撃力の高い順に上限まで・選ばない）（10/21 ソーラーロボの効果をキーワード化）。


### 本文の中のキーワード（見出しには出さず、本文で太字。詳細画面で説明を添える）
- **破裂N**：そのロボの電池を1本破壊し、そのロボにNダメージ。「電池を外す」はダメージなし（10/21 追加。Nを変えたカードを今後作れるように数字付き）。

### ライフ
- 回復は上限を超えてよい。

## ローグライトの流れ（確定）
- ラン開始時に、自分のテーマ＋共通から候補3枚を見て1枚取り、デッキから1枚抜く（実装時に追加。第1戦から相手とテーマのカードの枚数をそろえるため）。
- 全5戦。デッキ10枚・ライフ7で開始し、1勝ごとにデッキ+2枚・ライフ+2（相手も同じ規模）。
- 相手のデッキ：基本デッキから r 枚抜き、テーマのカードを 3(r-1)+1 枚（足りなければ共通から）。CPUは第1戦「よわい」、第2・3戦「ふつう」、第4・5戦「つよい」（シミュレーションは第1〜3戦ふつう・第4・5戦つよいのまま）。
- 引き分けは同じ回戦をやり直し。ランは対戦と対戦の間で保存（対戦の途中で閉じると、その回戦の最初から）。
- 報酬：候補6枚から3枚取り、デッキから1枚抜く。
- 一度取ったカード・抜いたカードは、そのランでは候補に出ない。
- 自分はラン開始時に5テーマから2つをランダムに割り当て。候補は「その2テーマ＋共通」から出る。レアは出にくい。
- 相手は1テーマのデッキ。
- 同じカードの複数枚は、特殊イベント（コピー機・レアパーツ屋・大量生産など）でのみ。

## 特殊イベント（10/21 実装）
勝利のたびに「報酬→1枚抜く」のあと、文（看板）が1つ出る。入るか通り過ぎるかだけ決める。入ると、その文のイベントから1つが抽選で起きる（10/21 変更：以前はイベント2つから選ぶ形だったが、悪いイベントを誰も選ばないため）。第5戦の勝利後は無し。パーツは同じものを2回は取れない。
強いイベント（★）は1つの文にだけ、弱いイベントは2つ以上の文に入れる（強いほど出にくい）。

### 文とイベント
- 錆びた看板の露店がある。 → 闇市、ジャンクくじ、借金
- ガラクタの山の向こうで物音がする。 → ジャンクくじ、解体ヤード、付属電池化
- 怪しい男が手招きしている。 → 闇市、借金、★レアパーツ屋
- 空が急に暗くなってきた。 → 異常気象、ハンデ戦、エリート戦
- 大きな足跡が続いている。 → エリート戦、ハンデ戦、偵察、分かれ道
- 道が二手に分かれている。 → 分かれ道、偵察、よそのテーマ
- 見慣れないロボがこちらを見ている。 → よそのテーマ、エリート戦、異常気象
- 古い工場の明かりがついている。 → 大量生産、付属電池化、★改造工場
- ロボの部品が箱に詰まっている。 → 解体ヤード、大量生産、★コピー機
- 誰も使っていない倉庫がある。 → ★予備バッテリー、★装甲板、★作業台、★先読み回路


### A デッキ
- コピー機：デッキのカード1枚を複製する。
- 大量生産：テーマのカード1枚を複製する。代わりに、次に抜くカードは基本カード以外から選ぶ。
- レアパーツ屋：レアだけの候補3枚から1枚もらう。
- 解体ヤード：デッキからカードを2枚抜く。
- よそのテーマ：自分のテーマ以外のカード3枚から1枚もらう。

### B 改造
- 改造工場：ロボ1枚を改造する（攻撃力+1か、電池上限+1）。
- 付属電池化：付属電池のないロボ1枚に、付属電池を付ける。

### C パーツ
- 予備バッテリー：パーツ：毎試合、最初に起動したロボに電池+1。
- 装甲板：パーツ：毎試合、ライフ+2で始まる。
- 作業台：パーツ：毎試合、手札+1枚で始まる。
- 先読み回路：パーツ：毎試合、始まった時に山札の上3枚を見て、引く順番を決められる。

### D 取引・賭け
- 闇市：ライフが以後ずっと2減る。代わりにレアの候補2枚から1枚もらう。
- ジャンクくじ：半分の確率でレアを1枚もらう。外れると「サビ」（使えないカード）がデッキに入る。
- 借金：ランダムにカードを2枚もらう。代わりに次の対戦はライフ−3。

### E 特殊な対戦
- エリート戦：次の相手が強くなる（デッキ+2枚・CPUが1段階強い）。勝てば報酬がもう1回。
- ハンデ戦：次の対戦は自分のライフが半分。勝てばレアの候補3枚から1枚。
- 異常気象：次の対戦は、お互いのロボの電池上限+1。

### F 情報・選択
- 偵察：次の相手のデッキの中身と、その次の相手のテーマが分かる。
- 分かれ道：次の相手を、2つのテーマから選ぶ。
